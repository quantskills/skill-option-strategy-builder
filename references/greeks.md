# 希腊字母口径与 BS 补算说明 (greeks)

## 数据来源优先级
1. **接口真实值**：`get_option_risk_indicators` 返回 `delta/gamma/vega/theta/rho`（+ `symbol/name/exchange/date`）。ETF/指数期权（50ETF、300ETF）五个希腊字母通常齐全，**优先直接用**。
2. **BS 模型补算**：任一希腊字母为 `None` 时，用 Black-Scholes 模型补算该字段，并在 `degraded` 中声明 `bs_filled` 字段列表。

> ⚠️ 实测坑（2026-07-27）：**商品期货期权（如豆一 A2507）的 gamma/vega/theta 大量为 None，只有 delta 有值**。完整希腊字母以 ETF/指数期权为准。本技能对缺失字段一律 BS 补算并声明，不静默留空。

## BS 模型实现（纯标准库）
`scripts/pricing.py` 用标准库 `math` 实现 Black-Scholes，**不依赖 numpy/scipy**：
- 正态累积分布 `N(x) = 0.5·(1 + erf(x/√2))`，用 `math.erf` 实现。
- 正态密度 `n(x) = exp(-x²/2)/√(2π)`。

公式（连续分红率 q）：
```
d1 = [ln(S/K) + (r - q + σ²/2)·T] / (σ·√T)
d2 = d1 - σ·√T
认购 price = S·e^(-qT)·N(d1) - K·e^(-rT)·N(d2)
认沽 price = K·e^(-rT)·N(-d2) - S·e^(-qT)·N(-d1)
```

## 各希腊字母口径（单位标的、每份合约、年化）
| 希腊 | 含义 | 口径 |
|---|---|---|
| delta | 权利金对标的价的一阶敏感 | 认购 0~1、认沽 -1~0 |
| gamma | delta 对标的价的变化率 | 恒正（买方） |
| vega | 对波动率变动的敏感 | 对 σ **变动 1.0（即 100%）**；报告折算成 IV+1% 时 = vega/100 |
| theta | 时间价值衰减 | **每年**（负=每日损耗）；报告可折算每日 = theta/365 |
| rho | 对无风险利率变动的敏感 | 对 r 变动 1.0（100%） |

## 组合净希腊字母
`pricing.net_greeks`：Σ 方向(+买/-卖) × 数量 × 合约数 × 合约单位 × 单腿希腊字母。
- 买腿取 +、卖腿取 −。
- 已乘合约单位（`contract_size`，50ETF 期权为 10000）与合约数，故净 delta 直接是"标的涨 1 元时组合价值变化（元）"。

## 默认参数
- 无风险利率 r 默认 0.02（CLI `--rate` 可调）。
- 分红率 q 默认 0.0。
- IV 缺失时默认 σ=0.20，并在 `degraded` 声明。到期年数 T = (到期日 − 今日)/365。

> 希腊字母缺失以 BS 补算为近似值，与做市商模型可能有差异。仅供研究参考，不构成投资建议。
